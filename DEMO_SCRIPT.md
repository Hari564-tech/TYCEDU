# SwarVidya — Demo Video Script (Target: 2 minutes 20 seconds)

## 0:00–0:18 — Opening
**On screen:** SwarVidya home screen.

**Narration:** “Meet SwarVidya, a voice-first learning companion for Indian school students. Our idea is simple: students should be able to learn by speaking in the language they are comfortable with.”

## 0:18–0:38 — Problem
**On screen:** Show the language selector and the large microphone.

**Narration:** “Many students can explain their doubts in Telugu or Hindi, but typing long questions in English can be difficult. A text-heavy interface can become one more barrier between a student and learning.”

## 0:38–1:08 — Ask a doubt
**On screen:** Select Class 8, Science and Telugu. Tap the microphone and ask: “What is photosynthesis?” If speech recognition is unavailable, type the question or tap the sample prompt.

**Narration:** “In SwarVidya, the student chooses a class, subject and language, then asks a question by voice. The prototype turns speech into text and gives a short explanation using demo lesson content.”

## 1:08–1:28 — Listen
**On screen:** Show the answer card and tap Listen.

**Narration:** “The explanation is designed to be simple and can be read aloud using the device's speech voice. This helps students listen, repeat and understand.”

## 1:28–1:53 — Practise
**On screen:** Answer the quiz by tapping an option or using the quiz microphone.

**Narration:** “Learning continues with one small practice question. Students get instant feedback and a short explanation, so they can learn from every attempt.”

## 1:53–2:12 — Teacher view
**On screen:** Scroll to Teacher's view and show attempts, accuracy and topics to revisit.

**Narration:** “The teacher view turns practice activity into a simple snapshot: how many attempts were made, how students are doing, and which topics may need another explanation.”

## 2:12–2:25 — Close
**On screen:** Return to the SwarVidya name and tagline.

**Narration:** “This is an early prototype, built to validate one strong learning loop. SwarVidya: learn by speaking, understand in your language.”

## Recording checklist
- Use Chrome or another browser with Web Speech API support.
- Grant microphone permission before recording.
- Check that the selected language has a usable speech recognition and speech synthesis voice.
- If speech recognition is unavailable, use the sample question chips and tap quiz answers; explain that text fallback is included.
- Use the sample demo content; do not present the rule-based prototype as a connected AI tutor.
